# Travel Planner Android App

Flutter приложение для планирования путешествий с интеграцией к 4 бекенд сервисам.

## Структура проекта

```
lib/
├── external/           # Сервисы для работы с API
│   ├── api_client.dart       # HTTP клиент с автоавторизацией
│   ├── auth_service.dart     # Аутентификация
│   ├── trip_service.dart     # CRUD операции для поездок
│   ├── external_service.dart # Поиск мест и AI функции
│   ├── library_service.dart  # Библиотека публичных маршрутов
│   ├── offline_storage.dart  # Кэширование и оффлайн поддержка
│   └── sync_service.dart     # Синхронизация и конфликт-резолюция
├── model/              # Модели данных
│   ├── trip.dart            # Модель поездки с JSON сериализацией
│   ├── place.dart           # Модель места
│   └── app_colors.dart      # Цветовая схема
├── view/               # UI компоненты
│   ├── screens/             # Экраны приложения
│   └── widgets/             # Переиспользуемые виджеты
└── view-model/         # ViewModel классы для управления состоянием
```

## Настройка окружения

1. Создайте файл `.env` в корне проекта:

```env
# Окружение: dev или prod
ENVIRONMENT=prod

# Настройки для разработки (если ENVIRONMENT=dev)
DEV_AUTH_URL=http://localhost:8081/api/v1
DEV_PLANNER_URL=http://localhost:8082/api/v1
DEV_EXTERNAL_URL=http://localhost:8083/api/v1
DEV_LIBRARY_URL=http://localhost:8084/api/v1

# Настройки для продакшна (если ENVIRONMENT=prod)
PROD_AUTH_URL=https://www.putevod-app.ru/auth/api/v1
PROD_PLANNER_URL=https://www.putevod-app.ru/planner/api/v1
PROD_EXTERNAL_URL=https://www.putevod-app.ru/external/api/v1
PROD_LIBRARY_URL=https://www.putevod-app.ru/library/api/v1
```

2. Установите зависимости:

```bash
flutter pub get
```

3. Генерируйте код для JSON сериализации:

```bash
dart run build_runner build
```

## Основные функции

### 🔐 Аутентификация
- Автоматическое обновление JWT токенов
- Русскоязычная обработка ошибок
- Защищенное хранение токенов

### 🗺️ Управление поездками
- CRUD операции для поездок
- Совместное редактирование с конфликт-резолюцией
- Публикация маршрутов в библиотеку
- Система версионирования для предотвращения конфликтов

### 📱 Оффлайн поддержка
- Кэширование данных с помощью Hive
- Очередь синхронизации для оффлайн операций
- Автоматическая синхронизация при восстановлении сети

### 🌍 Внешние сервисы
- Поиск мест с автодополнением
- Геокодирование адресов
- AI генерация списков вещей для поездки

### 📚 Библиотека маршрутов
- Просмотр публичных маршрутов
- Фильтрация по различным критериям
- Популярные и высокорейтинговые маршруты

## API Интеграция

### Сервисы
1. **Auth Service** (`https://www.putevod-app.ru/auth/api/v1`)
   - Регистрация, вход, восстановление пароля
   - Управление токенами

2. **Planner Service** (`https://www.putevod-app.ru/planner/api/v1`)
   - CRUD операции для поездок
   - Совместное редактирование
   - Приглашения и публикация

3. **External Service** (`https://www.putevod-app.ru/external/api/v1`)
   - Поиск мест Google/OpenStreetMap
   - AI функции для планирования

4. **Library Service** (`https://www.putevod-app.ru/library/api/v1`)
   - Публичная библиотека маршрутов
   - Поиск и фильтрация

### Конфликт-резолюция
Приложение автоматически обрабатывает конфликты при совместном редактировании:
- Проверка версий при каждом обновлении
- Диалоги предупреждения о конфликтах
- Возможность принудительного обновления или сохранения локальных изменений

## Архитектура

### Паттерны
- **MVVM** с Provider для управления состоянием
- **Repository Pattern** для абстракции данных
- **Singleton** для HTTP клиентов
- **Observer** для синхронизации данных

### Оффлайн стратегия
1. **Cache-First**: Сначала загружаем из кэша
2. **Network-Then-Cache**: Обновляем из сети, сохраняем в кэш
3. **Offline Queue**: Очередь операций для выполнения при подключении

## Структура API ответов

### Trip Model
```json
{
  "id": 1,
  "title": "Путешествие в Париж",
  "description": "Описание поездки",
  "startDate": "2024-01-15",
  "endDate": "2024-01-22",
  "version": 1,
  "isPublished": false,
  "places": [...]
}
```

### Error Handling
Все API ошибки обрабатываются централизованно с русскоязычными сообщениями:
- 401: Автоматическое обновление токена
- 409: Конфликт версий с диалогом резолюции
- 500: Повтор запроса с экспоненциальной задержкой

## Известные проблемы

1. При первом запуске необходимо интернет-соединение
2. Синхронизация может занять время при большом количестве данных
3. AI функции требуют активного подключения к сети
